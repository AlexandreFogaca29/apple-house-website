# 🍎 Apple House Website

> Website institucional e e-commerce responsivo focado na apresentação de produtos e otimização da experiência do utilizador (UX/UI).

---

### 💻 Sobre o Projeto
O **Apple House Website** é uma aplicação web desenvolvida para simular uma plataforma moderna de apresentação e venda de produtos. O objetivo principal do projeto foi aplicar boas práticas de desenvolvimento Front-End, garantindo uma navegação fluida, layout intuitivo e total adaptabilidade a diferentes tamanhos de ecrã (desktops, tablets e smartphones).

---

### ✨ Principais Funcionalidades
- 📱 **Design Totalmente Responsivo:** Interface adaptada para dispositivos móveis e desktops.
- 🎨 **Interface Moderna:** Layout focado em usabilidade e estética limpa.
- ⚡ **Navegação Interativa:** Elementos dinâmicos para melhorar a experiência do utilizador.

---

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e acessibilidade.
- **CSS3:** Estilização avançada, Flexbox/Grid e suporte a media queries para responsividade.
- **JavaScript:** Lógica de interatividade e manipulação do DOM.
